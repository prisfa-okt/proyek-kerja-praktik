# Proyek Kerja Praktik

Pengembangan WebGIS sebagai visualisasi informasi usaha skala besar di Kabupaten Sidoarjo.

## Teknologi
- Google Apps Script
- HTML
- JavaScript
- Google Maps API

## Struktur File
- Code.gs : fungsi utama aplikasi
- GeoJson.gs : pengolahan data GeoJSON
- Index.html : halaman landing
- Peta.html : tampilan dashboard, statistik, dan data usaha
